# 🍳 Eat! — Telegram-бот с рецептами

Учебный проект команды **«Бронированные вафельные стаканчики»**

Бот помогает быстро найти блюдо под свои цели: фильтрует рецепты по категории
(завтрак / обед / ужин), диетическим предпочтениям и диапазону калорийности,
показывает БЖУ и пошаговые инструкции. Рецепты можно сохранять в избранное,
оценивать и предлагать свои — после модерации они попадают в общий каталог.

## Возможности

- Каталог рецептов с фильтрами: категория, диета, диапазон калорийности
- Поиск по названию
- Карточка рецепта: БЖУ, калории, время приготовления, пошаговая инструкция
- Избранное
- Отзывы и оценки 1–5
- Предложение собственных рецептов
- Модерация предложенных рецептов (панель администратора внутри бота)

## Стек

| Слой | Технология |
|---|---|
| Бот | Python 3.12+, aiogram 3 |
| БД | SQLAlchemy 2.0 (async) + Alembic; SQLite → PostgreSQL |
| Конфигурация | pydantic-settings |
| Качество | ruff, pytest + pytest-asyncio, GitHub Actions |

## Запуск

> Проект в разработке (спринт 1 из 4) — раздел дополняется по мере готовности.

~~~bash
git clone https://github.com/KoTiKo43/eat-bot.git
cd eat-bot

py -3.12 -m venv .venv        # Linux: python3.12 -m venv .venv
.venv\Scripts\Activate.ps1    # Linux: source .venv/bin/activate

pip install -r requirements-dev.txt

cp .env.example .env          # затем вписать BOT_TOKEN от @BotFather

alembic upgrade head          # создать БД и справочники
python -m db.seed             # тестовые рецепты (появится в спринте 1)
python -m bot                 # запуск бота (появится в спринте 1)
~~~
